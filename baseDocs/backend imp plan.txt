============================================================ PROJECT CONTEXT ============================================================
Frontend: Next.js
Backend: Express.js
Database: Supabase PostgreSQL
ORM: Prisma
Authentication: Express-owned JWT
Storage: Supabase Storage through Express relay
Notifications: Express API + frontend polling (Supabase Realtime not used)
SMS: AfroMessage by default, but provider must be abstracted for future replacement
Payment: Cash on Delivery only
Architecture:
Next.js Frontend -> Express API -> Supabase PostgreSQL / Supabase Storage
Important strategy:
•	Supabase Auth is not used.
•	Express owns all authentication.
•	Phone OTP and Google OAuth are the only authentication methods.
•	Express generates JWT access tokens and refresh tokens.
•	Supabase service role key must never be exposed to the frontend.
•	Frontend must never write directly to Supabase database.
•	Frontend must never upload directly to Supabase Storage.
•	Customer notifications are discovered by polling Express, not Supabase Realtime.
•	All database and storage writes must go through Express.
•	Use JavaScript unless there is a strong reason to use TypeScript.
•	Keep code simple, readable, beginner-friendly, and modular.
